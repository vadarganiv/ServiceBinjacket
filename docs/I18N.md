# I18n

## Locales

- `sq` (Albanian) — primary, default.
- `en` (English) — secondary.

## Routing

- `/` → 308 redirect → `/sq`.
- `/sq/...` и `/en/...` — public.
- `/admin/...` — без locale prefix, admin UI в MVP English.
- Language switcher (в header):
  - сохраняет текущий path: `/sq/products/iphone-12` ↔ `/en/products/iphone-12` (slug разный — см. ниже);
  - на мобильном доступен из burger menu.

## Slugs

Каждая локализованная сущность имеет `SlugSq` и `SlugEn`. Switcher должен подменять slug по той же сущности (через product/service ID, не строковый join).

Если en-slug отсутствует — switcher на `en` ведёт на `sq`-страницу (fallback) и логирует missing slug.

## Translation files

```
frontend/messages/sq.json
frontend/messages/en.json
```

Структура ключей (namespacing):

```
common.*            — кнопки, статусы, общие лейблы
nav.*               — навигация, header, footer
home.*              — главная
products.*          — каталог, фильтры
productDetails.*    — карточка товара
services.*
serviceDetails.*
repairRequest.*     — форма
checkout.*          — оформление
delivery.*
payment.*
warranty.*
contact.*
errors.*            — error messages (для UI; backend коды → текст)
success.*           — success messages
admin.*             — admin UI (en только в MVP, sq не требуется)
```

## Key rules

- Все public UI-тексты — только через ключи. Никаких строковых литералов в `.tsx`.
- Каждый ключ должен существовать в `sq.json` И в `en.json`.
- Если en-перевод не готов — допустимо временно дублировать sq-значение и пометить TODO в комментариях `_meta.todo_en`.
- Albanian-тексты, не проверенные носителем, помечать `_meta.needs_native_review`.

## Backend localization

- Локализованные поля в БД (`*Sq`, `*En`) — см. `docs/DATA_MODEL.md`.
- API возвращает DTO с одним полем `name` (без суффикса) по `?locale=`.
- Fallback `en→sq` реализуется в Application маппере, не в EF query, не в контроллере.

## SEO

Каждая public page рендерит:

- `<title>` локализованный.
- `<meta name="description">` локализованный.
- `<link rel="canonical">` — на текущий locale URL.
- `<link rel="alternate" hreflang="sq" href=".../sq/...">`.
- `<link rel="alternate" hreflang="en" href=".../en/...">`.
- `<link rel="alternate" hreflang="x-default" href=".../sq/...">`.
- OpenGraph (`og:title`, `og:description`, `og:locale`).

## Checks (skill `i18n-check`)

Перед коммитом UI-изменений запустить skill — проверяет:

1. Все ключи в `sq.json` есть в `en.json` и наоборот.
2. Нет хардкодных строк в `app/**/*.tsx` и `features/**/*.tsx` (heuristic — алгоритм в самом skill).
3. Все `*Sq` в БД имеют соответствие `*En` (для опубликованных сущностей).
